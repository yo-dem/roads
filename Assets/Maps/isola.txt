# ==========================================================================================
#  Mappa di Roads — si modifica con un editor di testo (in futuro: con l'editor apposito)
# ==========================================================================================
#
#  Sotto [mappa] c'è la griglia. Ogni cella è un quadrato di territorio (96 x 96 unità) e sta
#  nelle colonne e righe PARI del testo. La lettera della cella dice com'è il territorio:
#
#     ~  mare            p  prato          f  bosco fiorito
#     a  bosco d'autunno n  valle innevata
#
#  I territori sfumano l'uno nell'altro a metà strada tra le celle; il mare forma la costa.
#  In alto c'è il nord.
#
#  Le STRADE non si disegnano: le traccia il gioco. Si mettono solo i centri abitati e i
#  punti di riferimento, con un simbolo della legenda in qualunque posizione della griglia
#  (anche tra le celle, negli spazi). Il gioco poi costruisce:
#     - la città: un reticolo di vie e incroci, palazzi alti al centro e villette in periferia
#     - i paesi: via principale verso la città, una via dietro, la piazza, case basse
#     - le statali asfaltate che dai paesi portano in città
#     - gli sterrati tra un paese e l'altro (attraverso i boschi), verso le cascine sparse
#       in campagna e verso ogni punto di riferimento
#  I paesi si spostano un poco da soli se dove li si mette c'è un fiume o la costa.
#
#  Voci:
#     partenza: colonna, riga   la cella vicino a cui si parte (contate da 0 in alto a
#                               sinistra); l'auto parte sulla strada più vicina, verso la città
#     fiumi: colonna, ...       colonne con un fiume nord-sud (sulle strade nasce un ponte)
#     X = tipo : Nome           legenda dei simboli
#                               tipi: città (una sola), paese,
#                                     faro, mulino, castello, torre, antenna, campanile
# ==========================================================================================
