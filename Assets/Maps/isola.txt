#
#  Sotto [mappa] c'è la griglia. Ogni cella è un incrocio con il territorio attorno (96 x 96
#  unità). Le celle stanno nelle colonne e righe PARI del testo; in mezzo ci sono le strade:
#
#     p-p      il trattino tra due celle = strada est-ovest
#     |        la barra sotto una cella  = strada nord-sud (verso la cella di sotto)
#     p F p    una lettera MAIUSCOLA tra quattro celle = punto di riferimento (vedi legenda)
#
#  Quartieri (lettera della cella):
#     ~  mare            p  prato          f  bosco fiorito
#     a  bosco d'autunno n  valle innevata
#     s  paese (case basse col tetto a falde, marciapiedi, lampioni)
#     c  città (palazzi alti, strade dritte e asfaltate)
#  I quartieri sfumano l'uno nell'altro a metà strada tra le celle; il mare forma la costa.
#  Le strade che finiscono in mare vengono ignorate. In alto c'è il nord.
#
#  Voci:
#     partenza: colonna, riga   la cella dove si parte (contate da 0 in alto a sinistra);
#                               l'auto parte verso est, quindi lì serve una strada verso est
#     fiumi: colonna, ...       colonne con un fiume nord-sud (scorre accanto alla strada
#                               nord-sud della colonna; sulle strade est-ovest nasce un ponte)
#     X = tipo : Nome           legenda dei punti di riferimento
#                               tipi: faro, mulino, castello, torre, antenna, campanile
# ==========================================================================================
